# AI image prompts for the oral photos

Use these with any image generator. For each scene:
1. Generate the image, landscape 4:3 (or 3:2), at least 1200 px wide.
2. Save it in `public/images/oral/` with the exact file name in the first column (same name and extension).
3. Keep the **same** file name, so `src/lib/data.ts` needs no change.
4. Add a credit to `src/lib/oralImageCredits.ts`, e.g. author `AI-generated (<tool name>)`, license `AI-generated, no copyright claimed`, page `docs/oral-image-prompts.md`.

Shared style suffix (append to every prompt): *photorealistic, natural lighting, candid documentary style, no visible text or logos, no real identifiable people, diverse young people aged 14-18.*
